关于这个站点

这是一个持续生长的个人知识站点，主要记录技术学习、科研过程，以及那些值得在未来重新阅读的思考。

写作范围

  • 技术学习中的问题、路径与可复用实践
  • 科研过程中的观察、假设、方法和下一步
  • 有明确来源与个人判断的资源整理

写作原则

尽量保留问题出现时的上下文；把尚未完成的部分写清楚；在获得新的证据后持续更新旧笔记。

如果你也在做类似的学习或研究，欢迎通过 GitHub 与我交流。
